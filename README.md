# chuckscasa.com

Link-in-bio site for Chuck's Casa, hosted on GitHub Pages.

- `index.html` is the page.
- The featured YouTube video is set in `scripts/update_latest.py` (`FEATURED_ID`). Change it and commit; the action writes `latest.json` with the title.
- Links to jasmineinitiative.org carry `utm_source=chuckscasa` so donations from this page are trackable.
